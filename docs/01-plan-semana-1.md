# Plan de trabajo - Semana 1

## Objetivo

Preparar el entorno tecnico, el repositorio, la documentacion base y la estructura inicial del proyecto Frontstage NutriBot.

## Alcance

Durante esta semana se trabajara en:

1. Configuracion del repositorio.
2. Creacion de ramas de trabajo.
3. Instalacion de React, Vite y TypeScript.
4. Configuracion compatible entre Linux y Windows.
5. Creacion de documentacion inicial.
6. Preparacion del contrato JSON.
7. Primer commit funcional.

## No incluido esta semana

- Conexion real con OpenAI, Groq u otra API.
- Backend definitivo.
- Autenticacion de usuarios.
- Base de datos.
- Gamificacion avanzada.

## Roles iniciales

### Product Owner y Project Manager

Responsable de organizar tareas, revisar requerimientos, documentar avances y validar entregables.

### Desarrollador Frontend

Responsable de crear componentes de interfaz, implementar chat, Mock API y estados cognitivos.

## Entregables

- Repositorio configurado.
- Rama develop creada.
- Proyecto React TypeScript funcionando.
- README actualizado.
- Carpeta docs creada.
- Contrato JSON documentado.
- Configuracion compatible Linux Windows.
